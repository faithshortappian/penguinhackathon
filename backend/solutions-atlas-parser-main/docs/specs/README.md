# Specification Documents

This directory contains the authoritative specification for the v3 unified architecture of the Appian Parser.

## Active Spec

| Spec | Status | Description |
|------|--------|-------------|
| [v3-unified/](./v3-unified/) | **Approved** | Unified data layer, versioning, delta pipeline, dependency graph, and MCP query surface |

The v3-unified spec consolidates three previously separate proposals (Release Versioning, Delta Parsing, Dependency Graph & Deduplication) into a single coherent architecture. All open questions have been resolved.
